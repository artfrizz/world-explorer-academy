# World Explorer Academy

Простой яркий курс английского для ребёнка: 50 коротких уроков, цветные картинки, озвучка, выбор картинки и слова, сборка первых фраз и словарь для повторения.

После каждого урока — мини-тест без картинок и разбор ошибок. В «Моих словах» можно повторить 20 вопросов, а также выбрать слова с частыми ошибками. Вкладка «Предложения» предлагает вставить знакомое слово в короткую фразу. Ответы не переключаются автоматически: правильный и ошибочный варианты подсвечиваются, затем ребёнок нажимает «Дальше». Статистика ошибок и результаты сохраняются вместе с остальным прогрессом.

## Запуск без установки

Скачайте файл **[world-explorer-academy.html](./world-explorer-academy.html)** (на GitHub: откройте файл → **Download raw file**) и откройте его двойным кликом в браузере. HTML содержит все стили, код и встроенные цветные картинки; интернет и сервер не нужны. Озвучка зависит от доступных голосов браузера/Windows.

## Прогресс и перенос

Прогресс автоматически сохраняется в локальном хранилище браузера. Кнопки **«Сохранить прогресс»** и **«Загрузить прогресс»** есть над содержимым каждой страницы. Переносите скачанный JSON-файл между компьютерами; импорт объединяет достижения, не уменьшая звёзды, XP и число открытых стран. Рекомендуется регулярно сохранять файл отдельно, особенно перед очисткой данных браузера или заменой HTML на новую версию. Для `file://` браузеры могут изолировать хранилище по-разному, поэтому JSON — надёжный способ переноса.

Формат сохранения имеет версию. Загрузчик понимает старый формат `world-explorer-academy-v1`, сохраняет неизвестные будущие поля/уровни/слова и отклоняет файлы из более новой несовместимой версии, чтобы не повредить данные. Старые уроки сохраняются в файле и не смешиваются с новыми 25 уроками. При изменении названия слова в будущих выпусках следует добавить его старое и новое имя в `wordAliases` (`src/engine.ts`); при изменении схемы добавить миграцию и увеличить `SCHEMA_VERSION`. Локально поддерживаются основная и резервная копии.

## Разработка

Нужен Node.js. `npm install`, `npm run dev`, `npm test`, `npm run build`. Сборка создаёт обычную папку `dist/` и обновляет автономный файл в корне. На Windows можно запустить `start.bat`.
