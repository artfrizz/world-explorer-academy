# World Explorer Academy

Интерактивный курс английского для юного исследователя: 6 экспедиций, карточки, повторение, конструктор предложений, голосовой блиц и паспорт стран.

## Запуск без установки

Скачайте файл **[world-explorer-academy.html](./world-explorer-academy.html)** (на GitHub: откройте файл → **Download raw file**) и откройте его двойным кликом в браузере. HTML содержит все стили, код и векторные иллюстрации; интернет и сервер не нужны. Озвучка зависит от доступных голосов браузера/Windows. Распознавание через микрофон может не работать в `file://` и без сетевых сервисов браузера — в этом случае доступны 4 карточки ответа.

## Прогресс и перенос

Прогресс автоматически сохраняется в локальном хранилище браузера. Кнопки **«Сохранить прогресс»** и **«Загрузить прогресс»** есть над содержимым каждой страницы. Переносите скачанный JSON-файл между компьютерами; импорт объединяет достижения, не уменьшая звёзды, XP и число открытых стран. Рекомендуется регулярно сохранять файл отдельно, особенно перед очисткой данных браузера или заменой HTML на новую версию. Для `file://` браузеры могут изолировать хранилище по-разному, поэтому JSON — надёжный способ переноса.

Формат сохранения имеет версию. Загрузчик понимает старый формат `world-explorer-academy-v1`, сохраняет неизвестные будущие поля/уровни/слова и отклоняет файлы из более новой несовместимой версии, чтобы не повредить данные. При изменении названия слова в будущих выпусках следует добавить его старое и новое имя в `wordAliases` (`src/engine.ts`); при изменении схемы добавить миграцию и увеличить `SCHEMA_VERSION`. Локально поддерживаются основная и резервная копии.

## Разработка

Нужен Node.js. `npm install`, `npm run dev`, `npm test`, `npm run build`. Сборка создаёт обычную папку `dist/` и обновляет автономный файл в корне. На Windows можно запустить `start.bat`.
